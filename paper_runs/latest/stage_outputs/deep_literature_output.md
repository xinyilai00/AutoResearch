RELEVANT METHODOLOGIES:
- **Sentometrics framework (Algaba et al., 2020)**: Proposes an integrated econometric methodology for transforming qualitative sentiment data — derived from text, audio, and visual sources — into quantitative sentiment variables suitable for econometric analysis. This framework explicitly addresses how to incorporate sentiment measures as explanatory variables in regression and time-series models, which is directly applicable to testing whether NLP-derived sentiment provides incremental predictive power beyond OHLCV-based models. The authors survey techniques for sentiment aggregation, weighting, and temporal alignment with financial variables.

- **Deep learning for financial sentiment analysis (Sohangir et al., 2018)**: Combines deep learning architectures with big data analytics specifically for financial sentiment analysis tasks. This work demonstrates how deep neural networks can be applied to large-scale financial text corpora to extract sentiment signals, establishing a methodological precedent for using deep learning both for sentiment extraction and for price prediction — the two components that must be compared in the target research question.

- **Financial Sentiment Analysis (FSA) dual-stream framework (Du et al., 2024)**: Provides a comprehensive survey identifying two main methodological streams in financial sentiment analysis: (1) task definition and technique development aimed at improving FSA performance through advanced methods and curated annotated datasets, and (2) application-oriented research that deploys FSA outputs for downstream financial prediction tasks. This taxonomy is critical for understanding how sentiment extraction methods and return prediction models have been coupled or studied independently.

- **News sentiment and stock price linkage analysis (Allen et al., 2019)**: Investigates the relationship between daily market news sentiment and stock prices using real-time online news and social media sources. This work employs sentiment scoring of financial news and tests its association with equity price movements, providing a methodological template for measuring the predictive relationship between text-derived sentiment and market returns.

- **Investor opinion mining from Twitter (Dickinson & Hu, 2015)**: Applies sentiment analysis specifically to investor opinions expressed on Twitter, using content and structural features of social media posts to determine overall market opinion. This methodology demonstrates how social-media-derived sentiment can be aggregated to form market-level opinion indicators, which is a key input modality for testing incremental predictive power.

- **Text representation and embedding techniques (Patil et al., 2023)**: Surveys the full spectrum of NLP text representation methods — from traditional bag-of-words and TF-IDF to modern contextual embeddings (e.g., BERT, GPT-based representations) — that serve as the feature extraction layer for any NLP-based sentiment pipeline. The choice of text representation directly affects the quality of sentiment signals and thus the magnitude of any incremental predictive contribution over OHLCV features.

- **Vector space models of semantics (Turney & Pantel, 2010)**: Establishes foundational methodology for representing word and document meaning in vector space, which underpins modern sentiment analysis approaches. The distributional semantics framework described here is the theoretical basis for how financial text can be converted into numerical features suitable for integration with time-series deep learning models.

- **Aspect-level sentiment analysis with hybrid deep learning and rule-based methods (Ray & Chakrabarti, 2019)**: Proposes a mixed approach combining deep learning with rule-based methods for aspect-level sentiment analysis on social media text. This hybrid methodology is relevant because fine-grained aspect-level sentiment (e.g., sentiment about earnings vs. sentiment about macro conditions) may provide more nuanced predictive signals than document-level polarity alone.

- **Supervised and unsupervised aspect category detection (Schouten et al., 2017)**: Uses co-occurrence data for detecting sentiment aspects in consumer reviews, demonstrating that decomposing sentiment into specific categories improves analytical granularity. Applied to financial text, this methodology could enable more targeted sentiment features (e.g., firm-specific vs. sector-specific sentiment) that may differentially predict returns.

- **Deep learning architecture foundations (Janiesch et al., 2021)**: Provides a systematic overview of machine learning and deep learning concepts based on artificial neural networks, including the architectural choices (CNNs, RNNs, LSTMs, Transformers) relevant to both the OHLCV time-series baseline model and the NLP sentiment extraction pipeline. Understanding these architectures is essential for designing a fair comparison between pure time-series models and augmented models.

PRIOR QUANTITATIVE RESULTS:
- **Sentiment-stock price linkage (Allen et al., 2019)**: Demonstrates that daily market news sentiment has a measurable relationship with stock prices, though the abstract does not report specific effect sizes or statistical significance levels for the incremental predictive contribution of sentiment beyond price-based features.

- **Deep learning superiority in financial sentiment tasks (Sohangir et al., 2018)**: Establishes that deep learning models applied to large-scale financial text data achieve strong performance on sentiment classification tasks, leveraging the advantage of massive data volumes. However, the specific incremental value of these sentiment features when combined with OHLCV-based deep learning models for return prediction is not quantified.

- **Sentometrics integration evidence (Algaba et al., 2020)**: Surveys the emerging field of integrating sentiment variables into econometric models and documents that sentiment data derived from textual, audio, and visual sources can be transformed into quantitative variables for econometric analysis. The survey identifies that the field is still developing standardized methodology for measuring the marginal contribution of sentiment variables.

- **Voting classifier performance for tweet sentiment (Rustam et al., 2019)**: Proposes a voting classifier ensemble for tweet sentiment classification that combines multiple base learners, demonstrating that ensemble approaches can improve sentiment classification accuracy on financial-domain tweets. Specific accuracy figures are not reported in the abstract.

- **SemEval benchmark results (Rosenthal et al., 2019; Nakov et al., 2019)**: The SemEval shared tasks produced benchmark results across 40+ participating teams for Twitter sentiment analysis, establishing performance baselines for sentiment classification systems. These benchmarks provide reference points for evaluating the quality of sentiment extraction pipelines used in financial prediction studies.

- **FSA technique performance landscape (Du et al., 2024)**: The comprehensive survey documents that financial sentiment analysis techniques have shown improving performance over the past decade, with transformer-based models generally outperforming traditional lexicon-based and shallow learning approaches on financial text classification tasks.

WHAT THIS QUESTION STILL NEEDS:

The retrieved literature reveals a significant gap between the individual components needed to answer this research question and the integrated experimental evidence that directly addresses it. While substantial work exists on financial sentiment analysis methodologies (Du et al., 2024; Sohangir et al., 2018), the econometric integration of sentiment variables (Algaba et al., 2020), and the general relationship between news sentiment and stock prices (Allen et al., 2019), none of the provided papers directly conducts the critical controlled experiment required: comparing a pure OHLCV time-series deep learning model against an augmented model that adds NLP-derived sentiment features, and rigorously testing whether the improvement is statistically significant across different market regimes. The existing literature treats sentiment analysis and time-series price prediction largely as separate methodological streams, and the intersection — where incremental predictive power is formally tested with appropriate statistical controls — remains underdeveloped.

Several specific methodological gaps must be addressed. First, the question of **market condition dependency** is almost entirely unexplored in the retrieved literature. No paper systematically examines whether the incremental value of sentiment features varies across high-volatility versus low-volatility regimes, trending versus mean-reverting markets, or periods of elevated versus subdued news flow. Second, the literature lacks standardized experimental protocols for ensuring a fair comparison between the OHLCV-only baseline and the sentiment-augmented model — including proper temporal train/validation/test splits, walk-forward validation to prevent look-ahead bias, and appropriate statistical tests (e.g., Diebold-Mariano tests for predictive accuracy comparison) rather than simple in-sample accuracy metrics. Third, while (Patil et al., 2023) and (Turney & Pantel, 2010) document the evolution of text representation techniques, and (Du et al., 2024) surveys financial sentiment methods, there is no systematic investigation of how the choice of NLP pipeline (lexicon-based vs. fine-tuned transformer vs. LLM-based sentiment extraction) affects the magnitude of incremental predictive power relative to the OHLCV baseline.

A new study must therefore be designed with the following elements to advance knowledge on this specific question: (1) a rigorous experimental framework that trains a state-of-the-art time-series deep learning model (e.g., LSTM, Transformer) on OHLCV data as the baseline, then systematically adds NLP-derived sentiment features from financial news and social media, testing incremental predictive power using out-of-sample statistical significance tests; (2) explicit market regime classification — using established volatility, trend, and liquidity indicators — to condition the analysis and determine under which conditions sentiment adds value; (3) multiple NLP sentiment extraction methods tested to isolate the effect of sentiment quality on incremental predictability; and (4) a sufficiently long and granular dataset covering diverse market conditions (bull markets, bear markets, crisis periods, and calm periods) for US equities, with proper controls for transaction costs and realistic trading constraints. Without this integrated experimental design, the field cannot move beyond demonstrating that sentiment correlates with returns in general to answering the precise question of when and why NLP sentiment provides genuine incremental predictive power beyond what sophisticated time-series models already capture from price and volume data alone.
